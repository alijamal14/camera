# Design — documentation site

Visual contract for the public docs at `docs/` → https://ali.mk313.com/camera/

## Direction

**Mode:** Read  
**Form:** Docsify (no build; GitHub Pages `/docs`) with VitePress/Starlight wayfinding: sidebar,
search, pagination, theme toggle.

**World:** Daylight desk — cool paper, ink navy, photographic daylight-cyan accent. Type: Sora (UI)
+ Atkinson Hyperlegible (body). Replaces the previous Jekyll Cayman default.
