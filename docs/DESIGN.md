# Docs site design

Development-only visual contract for https://ali.mk313.com/camera/

## Direction

**Mode:** Read  
**Form:** Docsify shell (no build; GitHub Pages `/docs`) with VitePress/Starlight wayfinding:
sidebar, search, prev/next, light/dark.

**World:** Daylight desk — cool paper, ink navy, photographic daylight-cyan accent. Fonts:
Sora (UI) + Atkinson Hyperlegible (body). Avoid Cayman/Jekyll default and purple/glow marketing docs.

## Tokens

- Paper `#F4F7FB` / raised `#FFFFFF`; dark paper `#0B1220`
- Ink `#0F1C2E`; accent `#0C6B8A`
- Measure ~72ch; sidebar 280px
